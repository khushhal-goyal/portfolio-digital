## ✨ Features

- **Cyber / Space UI Theme:** Interactive cosmic orbit visuals, glowing accents, and smooth hover micro-interactions.
- **Curated Project Portfolio:** Displays core engineering, AI/DS, and full-stack projects with live demo triggers and source code links.
- **Direct Mail Integration:** Quick-launch email contact workflow with animated confirmation states.
- **Digital Resume Access:** Direct view and download triggers for technical resume.
- **Cross-Platform Responsive Design:** Built for optimal presentation across desktop monitors, tablets, and mobile viewports.

---

## 🛠️ Tech Stack

- **Framework:** React / Vite, TypeScript
- **Styling:** Tailwind CSS, Framer Motion
- **Icons:** Lucide React
- **Architecture & Build:** Lovable.dev
- **Version Control:** Git & GitHub
